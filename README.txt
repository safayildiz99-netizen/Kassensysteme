WICHTIG
Die ZIP-Datei nicht einfach als ZIP in GitHub Pages liegen lassen.
1. ZIP auf deinem Computer entpacken.
2. In GitHub ein Repository erstellen.
3. index.html, .nojekyll und README.txt in die oberste Ebene des Repositorys hochladen.
4. Repository: Settings > Pages.
5. Source/Build: Deploy from a branch.
6. Branch: main, Ordner: / (root), dann Save.
7. Nach kurzer Zeit zeigt GitHub dort die öffentliche Pages-Adresse.

Die Online-Version verwendet eigene neue localStorage-Namen.
Alte kaputte Login-Daten aus vorherigen lokalen Versionen werden dadurch nicht übernommen.
